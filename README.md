# astock-investment-research

一个独立的 A 股投资研究 Skill：先用分级证据建立事实底座，再按问题需要完成快速核验、专项研究或完整深度报告。

它解决两个常见问题：一是研究只复述市场故事、缺少证据和反证；二是每个简单问题都被扩写成长篇报告。Skill 会自动选择最小充分深度，同时保留完整的基本面、财务、估值和风险研究能力。

> 本项目只提供研究方法与输出约束，不内置行情或财务数据库。涉及当前信息时，运行环境需要具备联网检索能力。

## 怎么使用

本 Skill 采用显式调用。请先输入 `$astock-investment-research`，再写研究问题：

```text
$astock-investment-research 快速核验：这条消息是真的吗？
$astock-investment-research 专项研究：重点分析中微公司的估值和订单。
$astock-investment-research 完整深度报告：按十部分框架分析中微公司。
```

如果已显式调用 Skill、但没有指定档位，Skill 会自动选择最小充分研究深度。未显式调用时，本 Skill 不参与自动路由。

## 功能

- 核验公告、传闻、订单、客户、认证、涨价与国产替代逻辑。
- 分析公司商业模式、产业链位置、护城河、管理层和增长空间。
- 诊断近五年与最新报告期的财务质量，并适配制造业、软件、银行、保险、券商和周期品。
- 使用 PE、PB、PS、EV/EBITDA、DCF、DDM、NAV 或 SOTP 等适用方法估值。
- 构建风险矩阵、12—24 个月三情景、多空辩论、催化剂和推翻条件。
- 解读最新财报，在证据允许时给出研究级评级、合理价值区间和持有期限。
- 对半导体、光模块、PCB、CCL、铜箔、电子布、存储、AI 算力等产业主题识别真实受益与业绩兑现。

## 三种研究深度

| 模式 | 何时使用 | 典型输出 |
|---|---|---|
| 快速核验（默认） | 消息真假、单一事实、公告含义、某项业务是否存在 | 简短结论、关键证据等级、缺口或反证、数据日期 |
| 专项研究 | 只问财务、估值、同行、增长、财报或某条产业逻辑 | 聚焦指定维度，补充必要的相邻证据，不生成全套报告 |
| 完整深度报告 | 明确要求完整、全面或十部分投资报告 | 完整十部分框架，核心正文约 3000—5000 个中文字符 |

显式调用后，“这份订单消息是真的吗？”默认走快速核验；“只分析宁德时代的估值”走专项研究；“给我一份招商银行完整深度报告”才进入完整深度报告。

“深度分析某一维度”表示该维度做深，仍属于专项研究；“深度分析公司”且没有限定范围，或明确说“完整、全面、十部分框架”，才进入完整深度报告。“简单点、说重点、别写太长”默认只压缩输出，不降低研究档位。

## 工作原理

```text
识别问题深度
→ 搜索并分级证据
→ 建立事实底座与反证
→ 执行所需投资分析模块
→ 输出结论、估值、风险和推翻条件
```

证据按可信度与原始程度分为五级：

| 等级 | 含义 |
|---|---|
| S | 公司、交易所或监管正式披露 |
| A | 可独立验证的高可信外部资料 |
| B | 需要交叉验证的第三方或产业资料 |
| C | 研报、媒体或专家观点，用于辅助理解 |
| D | 市场讨论与社媒，只能作为线索 |

研究遵循十步优先级：公司披露、交易所和监管、订单与客户、技术与资质、产业景气、财务与经营交叉验证、同行比较、反证、研究媒体、市场讨论。快速核验在证据充分后停止；完整深度报告系统覆盖所有适用步骤。

核心纪律包括：题材热度不等于业绩兑现，有相关业务不等于核心受益，涨价传闻不等于利润增长，客户认证不等于放量，股价上涨也不证明基本面改善。只有低等级资料时，Skill 会明确“证据不足”，而不是制造确定性。

## 安装

把本仓库目录复制到 Codex 的个人 Skills 目录：

```text
~/.codex/skills/astock-investment-research/
```

确保 `SKILL.md` 位于该目录根层，随后重新打开或刷新 Codex。也可以把仓库克隆到上述位置；本项目不要求安装额外脚本或 Python 依赖。

## 使用

可显式调用：

```text
使用 $astock-investment-research 核验“某公司拿到海外大单”是否属实。
```

```text
使用 $astock-investment-research，只分析某银行当前估值，不要写完整报告。
```

```text
使用 $astock-investment-research，为某公司写一份完整深度投资报告，数据截至今天。
```

建议提供公司名和证券代码，并说明希望的时间点；如有待核验的链接、截图或研报摘要，也可一并提供。由于本 Skill 关闭隐式调用，每一轮希望确保继续使用本方法时，最稳妥的方式是再次写出 `$astock-investment-research`。

## 数据与输出要求

每份研究都会尽可能披露：

- 股价及对应交易日。
- 最新财报期间与公告日期。
- 新闻和检索截止日期。
- 估值基准日、盈利口径和币种。
- 关键来源、证据等级、数据缺口与冲突。

评级和目标区间不是必填项。若缺少最新价格、关键财务、可靠估值依据，或核心命题只有 C/D 级资料，Skill 会选择“暂无评级”或只列待验证条件。使用目标区间时会同时说明方法、假设、置信度、风险与推翻条件。

- `report-templates.md`：快速核验、专项研究和完整深度报告三种输出结构。

## 设计原则

主 Skill 保持精简，只负责路由和硬约束；详细方法按需加载，避免简单问题被长流程拖慢。证据研究不是外部协作步骤，而是本 Skill 内部的第一阶段。分析结论的强度不得超过证据强度。

当前版本不包含估值脚本和固定数据输入格式，因为 A 股行业差异大，过早固化会让银行、保险、制造业和成长企业使用错误模型。未来若形成稳定数据规范，可以在保留行业适配的前提下增加可复算工具。
