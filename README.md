# A-Stock Investment Analysis

一个专注于 A 股投资分析的 Skill。它使用当前数据、公司事实和明确假设，完成基本面、财务、业绩、估值、同行、情景与风险分析，并把结果组织成可复算、可比较、可推翻的投资结论。

> 本项目提供分析框架与输出约束，不内置行情或财务数据库。涉及当前信息时，运行环境需要具备相应数据或联网检索能力。

## 核心能力

- 分析商业模式、行业结构、产业链位置、护城河、管理层和增长空间。
- 诊断近五年与最新报告期的盈利质量、现金流、资产负债表和行业特有指标。
- 拆解收入、价格、销量、成本、费用与利润之间的业绩传导。
- 使用 PE、PB、PS、EV/EBITDA、DCF、DDM、NAV 或 SOTP 等适用方法估值。
- 进行同行比较、股票池研究和不同投资目标下的条件排序。
- 构建风险矩阵、12—24 个月情景、催化剂、多空辩论和推翻条件。
- 解读财报、市场反应与公司指引，在输入充分时给出合理价值区间和研究级结论。

## 不负责的工作

本 Skill 不用于：

- 独立判断消息、传闻或单一事实的真假
- 纯行情或财务数据查询
- 自选股管理和模拟交易
- 固定规则分类
- 在缺少约束时提供精确仓位、金额或个体化买卖指令

## 三档分析范围

| 模式 | 何时使用 | 典型输出 |
|---|---|---|
| 快速分析 | 财报变化、估值变化或单一经营问题 | 简短结论、关键输入、计算和限制 |
| 专项分析 | 财务、估值、同行、增长、产业链、风险或股票池等有限维度 | 深入指定模块，并补充会改变结论的相邻分析 |
| 完整深度报告 | 明确要求完整、全面或十部分投资报告 | 完整十部分框架，核心正文约 3000—5000 个中文字符 |

“深度分析某一维度”仍属于专项分析；只有整体公司研究且未限定范围，或明确要求完整报告时，才进入完整深度报告。“简单点、说重点”只压缩表达，不降低分析标准。

## 工作流程

```text
明确问题、时点和投资期限
→ 获取或接收事实材料并统一数据口径
→ 选择基本面、财务、估值和风险模块
→ 计算与归因
→ 情景和敏感性分析
→ 输出结论、风险、失效条件和复核节点
```

## 独立运行与协作

本 Skill 不依赖外部研究材料：没有上游输入时，自行获取完成分析所需的数据和公司事实。已有结构化事实材料时，可直接接收其中的命题状态、来源、日期、支持或反对方向、冲突、缺口和置信度，保留原有证据标记而不重复定义分级。

外部材料只作为分析输入；盈利预测、财务判断、估值、情景、风险和最终投资结论仍由本 Skill 自行完成。

## 使用方式

本 Skill 支持隐式调用。当请求明确涉及 A 股基本面、财务、业绩、估值、同行、情景、风险或投资结论时，可以自动触发；也可以显式点名：

```text
$a-stock-investment-analysis 快速分析：这家公司最新季度毛利率为什么下降？
$a-stock-investment-analysis 专项分析：重点分析中微公司的估值和业绩弹性。
$a-stock-investment-analysis 完整深度报告：按十部分框架分析中微公司。
```

如果没有指定档位，Skill 会选择最小充分分析范围。

## 数据与计算要求

分析应尽可能披露：

- 股价及对应交易日
- 最新财报期间与公告日期
- 估值基准日、盈利口径和币种
- 关键数据来源、单位和缺口
- 关键公式、输入和必要中间结果
- 报告值、调整值、预测值与自行计算值
- 基准、乐观和悲观情景
- 敏感项、催化剂、风险和失效条件

数据不足时保留能够完成的分析，不给伪精确单点或无依据概率。

## 设计原则

主 Skill 只保留路由、分析骨架和输出契约；详细方法按需加载。分析结论必须能够追溯到数据、计算和假设，且强度不得超过输入质量与模型适用性。

当前版本不包含固定估值脚本和统一数据输入格式，因为银行、保险、制造业、软件与成长企业需要不同指标和模型。
