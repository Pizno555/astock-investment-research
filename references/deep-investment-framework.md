# 基本面与成长分析框架

本文件决定商业质量、行业地位、护城河、管理层、增长空间和机构视角如何分析。只在相关专项研究或完整深度报告中读取。

## 1. 公司与商业模式

先用一句话说明公司为谁解决什么问题、如何收费、价值由谁支付。再拆解：

- 按产品、地区、客户、渠道或业务分部列收入与利润来源；数据可得时同时列占比与变化。
- 识别一次性、低毛利、资本密集或强周期收入，不把所有收入视为同等质量。
- 说明成本结构、定价权、营运资本特征、资本开支和再投资需求。
- 判断商业模式是项目制、订阅制、平台、制造、资源、渠道、金融利差或其他类型。
- 描述公司在产业链的上游、核心环节或下游位置，以及价值量和议价权来源。

回答：靠什么赚钱、利润由什么驱动、增长是否可复制、现金能否回收、最脆弱的依赖是什么。

## 2. 行业定位与生命周期

判断行业处于导入、成长、成熟、周期上行、周期下行或结构衰退阶段。依据需求增速、渗透率、供给扩张、价格、库存、资本开支与竞争变化，而不是只凭叙事。

分析：

- 需求端：终端需求、客户资本开支、政策与技术驱动。
- 供给端：产能、准入、扩产周期、替代品和退出壁垒。
- 竞争结构：集中度、份额变化、价格竞争、行业利润池。
- 关键变量：价格、销量、产品组合、良率、利用率、汇率或原料成本。
- 公司位置：龙头、挑战者、细分冠军、弹性参与者或边缘配套。

## 3. 护城河评估

逐项寻找可验证证据：

- 品牌与市场地位。
- 网络效应与用户黏性。
- 转换成本与客户锁定。
- 成本、规模、供应链和制造效率。
- 技术、专利、工艺、良率和认证。
- 牌照、渠道、数据或稀缺资源。

护城河必须体现为持续的超额回报、稳定份额、较高留存、定价权、较低成本或更强现金创造。仅有专利数量、研发宣传或客户名单不够。

如用户需要评分，可给 1—10 分，但必须列出加分、扣分和证据；评分是分析摘要，不是独立事实。说明护城河在增强、稳定还是衰减。

## 4. 管理层与治理

核验：

- 核心管理层履历、任期与可验证经营结果。
- 战略承诺与实际交付记录，尤其是产能、订单、利润和现金流。
- 控股股东、实际控制人、董事会独立性和关联交易。
- 股权激励条件是否关注每股价值、现金流与资本回报，而非只追求规模。
- 融资、并购、分红、回购、减持和资本开支的资本配置质量。
- 财务重述、监管处分、频繁更换审计机构或高管等治理信号。

避免仅根据媒体形象评价管理层。把“说了什么”和“兑现了什么”分开。

## 5. 增长空间与兑现路径

### 市场空间

使用 TAM、SAM、SOM 时定义产品、区域、客户、时间与价格口径；优先自下而上测算。不要把全球宽口径 TAM 直接当公司的可获得收入。

### 增长驱动

分别评估：

- 行业自然增长与渗透率提升。
- 市占率变化。
- 新产品、新客户、新区域和渠道扩张。
- 提价、产品结构升级与降本。
- 产能释放、良率提升和并购并表。
- AI 应用、国产替代或技术路线变化。

每个驱动写清基数、量价关系、时间窗、所需投入、证据等级和限制因素。

### 预测

未来三年营收和利润预测应由销量、价格、份额、产能、毛利率等可解释变量驱动。五至十年只做方向性情景，不伪装成精确预测。输出基准区间、主要敏感项与导致偏离的信号。

## 6. 机构投资者视角

从可投资性而非故事完整性出发：

- 用 3—5 点概括核心投资逻辑，每点绑定证据和兑现时间。
- 列出未来 12—24 个月可观察催化剂，而非泛泛长期愿景。
- 检查市值、流动性、治理、信息透明度、周期位置和预期拥挤程度。
- 说明机构可能规避的原因：盈利波动、现金流弱、客户集中、估值高、治理风险、技术路线或政策不确定。
- 列出需持续跟踪的领先指标。

结尾回答：这是质量型、成长型、周期型、困境反转型、事件驱动型还是主题弹性型机会；相应的证据门槛、估值方法与持有逻辑是什么。
